# FocusGuard

Личное Android-приложение, которое делает Инстаграм менее затягивающим:

- **Ровное меню без Reels** — поверх нижней панели Инстаграма рисуется своя, из 4 иконок.
- **Не пускать во вкладку Reels** — если она всё-таки открылась, приложение сразу возвращает на главную.
- **Только один рилс** — рилс, присланный в директ, можно посмотреть, но при попытке листать дальше срабатывает «Назад».

Работает через «Специальные возможности» Android (Accessibility Service). Ничего не отправляет в интернет.

## Как установить на телефон

1. Открой на телефоне страницу **Releases** этого репозитория на GitHub (самая верхняя — свежая сборка).
2. Скачай `FocusGuard.apk` и открой его. Android спросит, можно ли устанавливать приложения из браузера — разреши.
3. Открой FocusGuard → «Открыть „Спец. возможности“» → включи FocusGuard.
4. Если переключатель серый: вернись в FocusGuard → «Открыть „О приложении“» → ⋮ (справа вверху) →
   «Разрешить ограниченные настройки» → снова шаг 3.
5. Открой Инстаграм.

Обновления ставятся поверх старой версии — разрешения сохраняются.

## Если что-то не работает

Включи в FocusGuard «Кнопка DUMP», открой проблемный экран в Инстаграме и нажми красную кнопку DUMP.
Потом в FocusGuard нажми «Отправить диагностику» — файл сохранится в «Загрузки/FocusGuard».
По нему видно, как Инстаграм назвал свои элементы, и это можно поправить в `Ig.kt`.

## Для разработчика

- Код: `app/src/main/java/com/focusguard/app/`
  - `FocusService.kt` — логика (что считается вкладкой Reels, свайпом и т.д.)
  - `Ig.kt` — все «опознавательные знаки» интерфейса Инстаграма
  - `NavBarOverlay.kt` — своя нижняя панель; иконки в `res/drawable/ic_*.xml`
- Сборка идёт автоматически в GitHub Actions (`.github/workflows/focus-app.yml`).
- Ключ подписи `keystore/focusguard.jks` — учебный, только для личной установки.

# FocusFeed

Второе приложение: Инстаграм «без лишнего». Внутри открыт сайт instagram.com, а всё ненужное вырезается прямо со страницы:

- лента всегда открывается в режиме «Подписки» — только те, на кого ты подписан, без рекомендаций;
- лента Reels недоступна, кнопки Reels и «Создать» убраны из меню;
- реклама, «Рекомендации для вас» и Threads скрыты;
- в поиске нет сетки рекомендаций — только строка поиска.

Остаются: истории, лента подписок, директ (и присланные рилсы), профили, подписчики/подписки, сохранённое.

Что прятать — описано в двух файлах, их можно править как обычный веб:
- `feed/src/main/assets/clean.css` — стили;
- `feed/src/main/assets/clean.js` — логика (редиректы, поиск рекламы по надписям).
